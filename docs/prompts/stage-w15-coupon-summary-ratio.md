## Задача (решение владельца 2026-09-25)

`JoomlaCoupon::getUserPercentCouponsSummary()` (~стр. 1688) – сводка на
карточке процентного промокода («Использований», «Всего прибыль» и др.,
поле `couponsSummary` в `business-data`).

Для заказов с `cashback = 0` и скидкой ≈10% сводка считает заработком
партнёра саму скидку (правило для старых 10%-промокодов). Проверка «≈10%»
написана с ошибкой:

```php
$discountRatio = ($totalSubtotal > 0) ? $discount / $totalSubtotal : 0;
```

`$totalSubtotal` – накопитель по **предыдущим** заказам купона, а не
сумма текущего заказа: у первого заказа правило не срабатывает никогда, у
остальных – почти случайно. Такие заказы выпадают из сводки, и карточка
промокода показывает меньше, чем учтено в балансе (баланс считает другой
путь – `JoomlaCoupon::applyCashbackFix()` в сборке заказов, он верный).

**Сделать:** считать долю от суммы **своего** заказа –
`$order->order_subtotal` (поле есть в белом списке `ORDER_SAFE_FIELDS`;
убедись, что это сумма до скидки, сверив с данными). Ноль/пусто в
знаменателе – как сейчас, доля 0.

## Проверка

1. **До правки** – прогон `couponsSummary` по всем партнёрам с одобренной
   заявкой (тинкер-харнесс по образцу W14: `storage/app/ppm-w14-summary-dump.php`
   – сброс `JoomlaCoupon::resetRequestCaches()` и `BusinessDataCache`
   перед каждым партнёром) → `storage/app/ppm-w15-summary-BEFORE.json`.
2. Правка, затем тот же прогон → `...-AFTER.json`, таблица изменений по
   промокодам (партнёр, промокод, поле, было, стало).
3. **Согласованность:** для каждого изменившегося промокода – сумма
   «Всего прибыль» в сводке теперь равна сумме начислений по этому
   промокоду в `credits.orders` его `business-data` (или объясни
   расхождение).
4. **Баланс не изменился ни у кого** – инструмент сверки:
   `docker exec -e PPM_SNAPSHOT_OUT=/var/www/storage/app/snap-W15-BEFORE.json laravel_backend php artisan tinker tools/balance-snapshot.php`
   до правки, `snap-W15-AFTER.json` после, затем
   `docker exec -e PPM_SNAPSHOT_A=/var/www/storage/app/snap-W15-BEFORE.json -e PPM_SNAPSHOT_B=/var/www/storage/app/snap-W15-AFTER.json laravel_backend php artisan tinker tools/balance-compare.php`
   – ожидается «ИТОГ: расхождений нет».
5. `php -l`, свежий PHP-процесс без warning/ошибок.
