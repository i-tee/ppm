## Правила сессии

- Одна сессия, **без суб-агентов**. Большие файлы читай фрагментами.
- **Git-мутаций не делаешь** (add/commit/switch/stash). Read-only
  `git status/diff/log` – можно.
- Репо в WSL: `~/dev-partner`. Команды – через
  `wsl -d Ubuntu-22.04 bash -lc '...'`, не Windows-git по UNC (CRLF).
  Команды с кавычками или `$` – в `.sh`-файл в `/tmp` WSL, после удалить.
- ☠️ **Получил отказ в разрешении (permission / классификатор) – остановись
  и напиши об этом в отчёте. Не обходи другим способом** (tinker, прямой
  SQL, другой инструмент) – даже если «это то же самое».
- Меняешь **только фронт** `resources/js/` (+ `locales/*.json`). Сервер,
  роуты API, миграции, `package.json` – не трогать.
- Вне задачи не чинить – найденное в отчёт.
- Тексты интерфейса – только через i18n (`ru.json` обязательно, `en.json` –
  те же ключи). Бренд – «Avicenna®», тире «–», обращение на «вы».
  Комментарии в коде – по-русски.
- Стек: Vue 3.5, Pinia 3 (другие геттеры – через `this`, не второй
  аргумент!), vue-router 4, Vuestic UI 1.10. Перед API пакета сверься с
  версией в `package.json` и документацией этой версии.

## Что сделать

### 1. Только программа «Агент» (п. 1 карточки)

- Выбор режима (`Types.vue`) скрыть: партнёр без одобренной заявки видит
  сразу анкету «Агента» (та же форма, что сейчас открывается для агента в
  `Types.vue`) и статус своей заявки. Карточек других режимов нет.
- Роуты `influencer`, `wholesale`, `distributor`, `types` – редирект на
  главную партнёра (файлы компонентов **не удалять**).
- Пункты режимов, которые `Sidebar.vue` строит из `/api/ps →
  cooperation_types`, – убрать.
- ⚠️ Форму анкеты по полям не меняй – поля переделывает этап 1.7
  следующей волной. Можно вынести её в отдельный компонент, если это
  упрощает, но поля и отправку оставь как есть.

### 2. Страницы партнёра вместо вкладок

Разнести `Agent.vue` на отдельные экраны (роуты с `meta.roles: ['partner']`):

| Пункт меню | Экран | Содержимое |
|---|---|---|
| Главная | `/dashboard` (Overview) | как сейчас (сводка) |
| Промокоды | `/dashboard/promocodes` | `CouponsList` + создание (`CreateCoupon`) |
| Статистика | `/dashboard/statistics` | пока – `CreditsList` (начисления); график добавит этап 1.5 |
| Выплаты и списания | `/dashboard/payouts` | баланс + «Вывести» (`PayoutModal`) + `DebitsList` |
| Реквизиты | `/dashboard/requisite` | как сейчас |
| Профиль | `/dashboard/account` | как сейчас |

- Роут `/dashboard/promocodes` сейчас указывает на заглушку
  `Promocodes.vue` – переиспользуй путь, заглушку можно заменить.
- `/dashboard/agent` – редирект на `/dashboard/promocodes` (ссылки из
  писем и закладок не должны сломаться).
- Баланс и кнопка «Вывести» – на «Главной» уже есть сводка; на «Выплатах»
  – обязательно. Ссылку на договор/условия (`contract_url`,
  `Conditions_Agent`) сохранить – на «Выплатах» или в шапке, где логичнее.
- Пункты «Промокоды / Статистика / Выплаты» показываются только партнёру
  с одобренной заявкой (как сейчас «Агент»); без заявки – «Главная»,
  «Анкета» (п. 1), «Профиль».
- Пункт «С чего начать?» **не добавляй** – его и страницу делает этап 1.8.
- События обновления данных (создание купона, выплата, чек → `businessStore.load({ force: true })`)
  должны работать на новых экранах так же, как в `Agent.vue`.
